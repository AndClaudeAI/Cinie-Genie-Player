# Sunnyside Summer School Website

A standalone static website for a summer school, built with plain HTML/CSS/JS
(no build step required). Highlights the school's daily akara-and-custard
tradition — every student gets 40 balls of freshly fried brown akara per day.

## Structure

- `index.html` — page markup (hero, about, the 40-ball promise, menu,
  programs, gallery, testimonials, enrollment form)
- `styles.css` — all styling, responsive down to mobile
- `script.js` — mobile nav toggle, footer year, enrollment form handling

## Running locally

Just open `index.html` in a browser, or serve the folder:

```bash
npx serve summer-school-site
```
